# 实时字幕

把 Windows 上**网页/系统正在播放的声音**，实时转成字幕显示。基于
[k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 的流式语音识别，
全程本地运行，不上传任何音频。

## 功能

- 实时字幕：说话内容逐字冒出来，一句话说完自动定稿分段
- 定稿精修：每句话定稿时用大模型重识别一遍并加标点，比纯流式更准
- 声音来源：系统声音（浏览器网页播放的声音，无需装虚拟声卡）/ 麦克风
- 深色大字字幕窗口，可调字号，可置顶悬浮在视频上
- 中英混合识别（普通话 + 英语）
- 首次运行自动下载模型（约 490MB，一次就好，存在项目目录的 `models` 文件夹里），之后完全离线
- 字幕自动保存：每次点「开始字幕」都会生成一个 `字幕_年月日_时分秒.txt`
  文本文件（每行 `[分:秒] 内容`），默认存在项目目录下的 `subtitles`
  文件夹，界面上可以直接更改保存位置（选择会记住），关掉窗口也不会丢

## 原理（一句话）

Windows 的 WASAPI loopback 能把“你听到的声音”当成麦克风录进来，
sherpa-onnx 的流式识别模型（zipformer 中英双语）边听边出字，延迟在
半秒以内。

## 使用（源码直接运行）

1. 在 Windows 上安装 Python 3.10–3.12（安装时勾选 Add to PATH）
2. 解压后双击运行 `run.bat`（第一次会自动装依赖，需要几分钟）
3. 首次运行还会自动下载识别模型（约 190MB，一次就好）
4. 声音来源选“系统声音”，点「开始字幕」
5. 打开网页播视频，字幕就实时出来了
6. 勾选「窗口置顶」可以把字幕悬浮在视频窗口上

以后想打包成单个 exe 再说：`build.bat` 和 GitHub Actions 配置都留着，
到时候双击 `build.bat` 或打个 tag 就行。

## 常见问题

- **没有字幕 / 全是空**：检查 Windows 默认播放设备是否有声音在播；
  网页标签页不要静音；系统音量不要为 0。
- **字幕延迟大**：int8 模型在普通 CPU 上远快于实时，一般是半秒内出字。
- **想识别自己说话**：声音来源换成“麦克风”。
- **模型下载慢/失败**：程序优先从国内镜像（ModelScope、hf-mirror）逐文件下载，
  镜像不可用时自动换源，实在不行再整包下载兜底。模型放在项目目录下的 `models`
  文件夹（老版本在用户目录的已下载文件会自动搬过来，不用重下）；重装时备份
  整个项目文件夹即可，拷到哪都能直接用。
